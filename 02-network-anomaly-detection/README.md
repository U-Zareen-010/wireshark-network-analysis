# Network Anomaly Detection with Wireshark

## Objective
Analyze captured network traffic to identify suspicious activity using Wireshark.

## Skills Practiced
- Packet capture
- Display filters
- Protocol analysis
- Traffic inspection
- Basic threat detection

## Topics Covered
- Network traffic baselines
- Packet filtering
- Network anomaly detection
- TCP SYN Flood analysis

## Source
This work was completed as part of the **"Wireshark for Security: Detect Network Anomalies"** Guided Project on Coursera. The notes, analyses, screenshots and documentation in this repository were created as part of my hands-on learning.
